# Code of Conduct

Be kind and respectful to everyone participating in this project. Assume good faith, welcome different perspectives, and offer constructive feedback.

Harassment, discrimination, threats, and personal attacks are not tolerated. Respect others’ boundaries and help keep this community welcoming.

To report a problem, open a GitHub issue or email the maintainer using the email address listed on their GitHub profile. For sensitive reports, prefer email and avoid sharing private information in a public issue.
