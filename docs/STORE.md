# The store

This repo is a tiny shop cart. It sells two things:

- **Factory mug** — $18.00
- **Rocket sticker** — $3.5

Add items to a cart, apply a coupon, and you receive a one-line receipt with the item count and the total.

## Coupons

- **SAVE10** — 10 percent off
- **FIVEOFF** — 5 dollars off

Shipping rules live in [the shipping page](SHIPING.md).

## Returns

Unopened items can be returned within 30 days for a full refund.
